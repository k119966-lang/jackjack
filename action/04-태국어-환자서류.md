# 04. 태국어 환자 서류 (초안 — 태국어 원어민·법률 검수 필수)

> 용도: 등록 후 의료해외진출법 제8조 게시·안내 의무 + 태국 PDPA 동의. **보건복지부 진료계약서 표준 양식은 MEDICALKOREA에서 받아 태국어 번역을 붙이세요**(아래에는 넣지 않음).
> 영어 게시는 필수, 태국어는 추가 권장.

---

## 4-1. 환자 권리 안내 (원내 게시용)

**สิทธิของผู้ป่วยชาวต่างชาติ | 외국인환자의 권리**

| ภาษาไทย | 한국어 |
|---|---|
| ท่านมีสิทธิได้รับคำอธิบายเกี่ยวกับการวินิจฉัย วิธีการรักษา และผลข้างเคียงที่อาจเกิดขึ้น เป็นภาษาที่ท่านเข้าใจ | 진단, 치료 방법, 발생 가능한 부작용을 이해할 수 있는 언어로 설명받을 권리 |
| ท่านมีสิทธิได้รับแจ้งค่ารักษาโดยประมาณก่อนเริ่มการรักษา | 치료 시작 전 예상 진료비를 안내받을 권리 |
| ท่านมีสิทธิตัดสินใจยินยอมหรือปฏิเสธการรักษาได้อย่างอิสระ | 치료에 자유롭게 동의하거나 거부할 권리 |
| ท่านมีสิทธิได้รับการคุ้มครองข้อมูลส่วนบุคคลและข้อมูลสุขภาพ | 개인정보·건강정보를 보호받을 권리 |
| ท่านมีสิทธิขอสำเนาเวชระเบียนของท่าน | 본인 진료기록 사본을 요청할 권리 |
| หากเกิดข้อพิพาท ท่านสามารถติดต่อคลินิก หรือสถาบันไกล่เกลี่ยข้อพิพาททางการแพทย์แห่งเกาหลี (K-Medi) ได้ | 분쟁 발생 시 의원 또는 한국의료분쟁조정중재원에 문의할 수 있음 |

คลินิกชูริริง (슈리링의원) · สถานพยาบาลที่ลงทะเบียนรับผู้ป่วยชาวต่างชาติ เลขที่ [등록번호] (외국인환자 유치의료기관 등록번호)

## 4-2. 시술 설명·부작용 안내 (동의서 첨부용)

**ข้อมูลก่อนทำหัตถการ: ชูริงค์ ยูนิเวิร์ส (Shurink Universe / Ultraformer MPT) | 시술 전 안내**

| ภาษาไทย | 한국어 |
|---|---|
| หัตถการนี้ใช้คลื่นอัลตราซาวด์ความเข้มสูงแบบโฟกัส (HIFU) | 이 시술은 고강도집속초음파(HIFU)를 사용합니다. |
| แพทย์เป็นผู้ทำหัตถการเองทุกช็อต | 모든 샷을 의사가 직접 시술합니다. *(사실일 때만)* |
| ใช้เวลาประมาณ [ ] นาที ไม่ใช้ยาสลบ | 약 [ ]분 소요, 수면마취를 하지 않습니다. *(실제 프로토콜대로)* |
| อาจมีอาการแดง บวม ตึง ชา หรือเจ็บชั่วคราว ส่วนใหญ่หายได้เองภายในไม่กี่วัน | 일시적인 붉어짐, 붓기, 당김, 저림, 통증이 있을 수 있으며 대부분 며칠 내 호전됩니다. |
| พบได้น้อย: รอยช้ำ ผิวไหม้ รอยนูน หรืออาการชาที่เป็นนานกว่าปกติ หากมีอาการผิดปกติโปรดติดต่อคลินิกทันที | 드물게 멍, 화상, 부어오름, 오래가는 저림이 생길 수 있습니다. 이상 시 즉시 연락해 주세요. |
| ผลลัพธ์แตกต่างกันในแต่ละบุคคล และไม่สามารถรับประกันผลได้ | 결과는 개인마다 다르며 보장할 수 없습니다. |
| โปรดแจ้งแพทย์หากท่านตั้งครรภ์ มีโรคประจำตัว ใช้ยาละลายลิ่มเลือด หรือมีโลหะ/ฟิลเลอร์บริเวณที่ทำ | 임신, 지병, 항응고제 복용, 시술 부위 금속·필러가 있으면 의사에게 알려 주세요. |
