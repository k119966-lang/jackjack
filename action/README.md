# 등록 전 실행 패키지 (슈리링의원 × 태국)

> 작성 2026-09-25 · 근거: `../research/thailand-shurink-marketing.md`
> 원칙: **등록증이 나오기 전에는 태국어 채널을 외부에 공개하지 않는다.** 그 대신 등록증이 나오는 날 바로 켤 수 있게 모든 걸 미리 만들어 둔다.

## 1. 등록 전 할 수 있는 것 / 없는 것

| 구분 | 등록 전 | 근거·메모 |
|---|---|---|
| 스스로 찾아온 외국인 **진료** | ✅ 가능 | 진료 자체는 불법이 아님. 금지되는 건 '유치'(예약 대리, 진료정보 제공, 교통·숙박 안내 등, 의료해외진출법 제2조 3호) |
| 태국어 광고·SNS 운영, 태국어 예약 창구, 가격 안내, 에이전시 소개 환자 받기 | ❌ 금지 | 미등록 유치 = 3년 이하 징역 / 3천만원 이하 벌금(제28조) |
| 한국에 사는 태국인 대상 태국어 할인·홍보 | ❌ 등록 후에도 금지 | 외국인환자가 아님 → 의료법 제27조 3항 유인 |
| **내부 준비물 제작**(서류 번역, 랜딩페이지 비공개 제작, 콘텐츠 촬영·보관, 질의서 발송) | ✅ 가능 | 외부 공개가 아니므로 유치 아님 |
| 등록 신청, 보험 가입, 관청·클래시스 질의 | ✅ 가능 | 등록은 **수수료 0원, 법정 처리 20일** |
| 국내(한국인) 대상 슈링크 마케팅 | ✅ 가능 | 기존 의료광고 규정대로 |
| 태국어 키워드·경쟁사 조사 | ✅ 가능 | 공개 활동 아님 |

→ 결론: 등록은 무료이고 20일이면 됩니다. 등록 **전에 광고로 우회할 방법은 찾는 것보다, 등록을 바로 신청하고 그 20일 동안 아래 준비물을 완성하는 편이 훨씬 빠르고 안전합니다.**

## 3. 제가 할 수 없는 것 (원장님 몫)

- 관청 제출, 보험 가입, 계정 개설(LINE OA·Meta), 결제, 전화·방문
- 기기 명판 확인(슈링크 구형 = Ultraformer III / 유니버스 = MPT) → **결과를 알려주시면 모든 문구를 거기에 맞춰 고칩니다**
- 태국어 최종 검수(제 태국어는 초안 수준입니다)

## 4. 알려주시면 바로 이어서 할 것

1. 기기 모델, 원장 전문의 여부, 의원 주소(강남 여부), 원화 가격표 → 서류·랜딩 빈칸 전부 채우기
2. 한국인 대상 슈링크 콘텐츠/광고 문구(의료법 기준 점검 포함)
3. 등록 후 공개할 LINE OA 자동응답·리치메뉴 문구, 첫 콘텐츠 15편 대본
