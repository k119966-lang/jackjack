# 슈리링의원 15초 애니매틱(프리비즈)

설계안의 컷 구성·타이밍·자막·엔딩 타이포를 그대로 구현한 15초 9:16 프리비즈 영상과 편집용 자산입니다. 실제 촬영·AI 생성 소재를 이 타임라인에 얹으면 본편이 됩니다.

## 파일

| 파일 | 내용 |
|---|---|
| `shuriring_15s_animatic.mp4` | 1080×1920, 30fps, 15.0초, 무음. 8컷, 60 BPM 그리드. 화면 하단의 컷 라벨·타임코드·비트 점은 프리비즈용 표시이며 본편에는 없음 |
| `endcard_night_1080x1920.png` | 엔딩 카드 나이트 마스터 (#0A0A0A / #F2F0EB / #D9D4CC). 12.0–15.0초에 그대로 사용 가능 |
| `endcard_day_1080x1920.png` | 엔딩 카드 데이 마스터 (#141414 / #FFFFFF / #E6E2DA) |
| `subtitles.srt` | 자막 3개의 인·아웃 시각 (편집 툴에서 불러와 상단 밴드 y 8–14%, 좌측 x 8%에 배치) |
| `timeline.csv` | 컷별 인·아웃, 사건 시각, 자막, 소재 출처(실촬영/AI) |
| `boards/` | 컷별 대표 프레임 8장 (콘티 보드) |

## 애니매틱에서 그대로 쓰는 것

- 컷 경계: 2.0 / 3.5 / 5.0 / 7.0 / 8.5 / 10.0 / 12.0 (하드컷 6회 + 12.0 검정 매치컷 위 로고 페이드인)
- 사건 시각: 1.0 반사선 중앙 통과 · 3.0 깜빡임 · 4.0 펜 접촉 · 6.0 핸드피스 집어들기 · 8.0 카트리지 안착 · 9.0 / 10.0 / 11.0 세 샷 · 11.57 팁 이탈 · 12.0 로고
- 자막: "먼저, 봅니다." 2.2→5.0 / "슈링크, 하나만." 5.2→8.5 / "한 샷, 한 샷." 9.0→11.8 (페이드인 0.3초, 아웃 0.2초, Noto Sans KR Medium, 글자 높이 프레임 5%)
- 엔딩 카드: 12.0→12.3 페이드인, 12.3→15.0 정지, 페이드아웃 없음

## 애니매틱과 본편이 다른 점

- C2·C6의 원장 얼굴은 프로필 사진을 로우키로 보정해 구도 확인용으로 넣은 것입니다. 실촬영에서는 시선을 환자 턱선(아래)으로, 무표정으로 촬영합니다.
- C1·C3·C4·C5·C7의 피사체는 형태·위치·움직임만 나타낸 프리비즈입니다. 질감(피부 모공, 젤 메니스커스, 카트리지 각인)은 실촬영 소재로 대체합니다.
- 렌더 스크립트: `render_animatic.py` (Python + Pillow + ffmpeg). 타이밍을 바꾸려면 `CUTS`, `SUBS`, 각 컷 함수의 로컬 타임라인을 수정합니다.
