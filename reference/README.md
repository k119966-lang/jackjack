| 소제목 (2행) | 18–19px | 35px | 약 1.67 |

> `--seal #9E3B2F`는 5.97:1로 통과. 자세한 내용은 PLAN.md의 결정 요청 항목 참조.

## 참고 자료의 한계 — 반드시 인지할 것

1. **모바일 캡처가 한 장도 없습니다.** 15장 전부 데스크톱(1525–1850px)입니다.
   브리핑 §0이 "모바일에서의 CTA 배치"를 참고 대상으로 지정했지만 이 스크린샷에서는 관찰할 수 없습니다.
   모바일 하단 고정 바는 참고 없이 새로 설계합니다.
2. 스크린샷마다 뷰포트 폭이 다릅니다(1525~1850px). 절대 px값은 이식할 수 없고 **비율만 유효**합니다.
3. 원본 URL이 없어 실제 CSS·인터랙션(스크롤 동작, 호버, 트랜지션)은 확인 불가입니다.
   정지 이미지에서 관찰 가능한 범위로만 판단했습니다.
