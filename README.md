# AURA CLINIC — 슈링크 리프팅 전문 홈페이지

PEGASUS CLINIC 스타일(연보라 + 흰색 + 하늘색, 넓은 여백, 오른쪽 떠다니는 예약바)로 만든
**슈링크 리프팅 단일 시술** 클리닉 홈페이지입니다.

프로그램 설치 없이 `index.html` 파일을 더블클릭하면 바로 열립니다.

---

## 1. 파일이 하는 일

```
index.html              ← 화면에 보이는 글자와 순서 (제일 많이 고치게 됨)
assets/css/style.css    ← 색, 크기, 여백 (디자인)
assets/js/main.js       ← 메뉴 열기, 등장 효과, 샷 수 계산기
assets/img/             ← 사진 넣는 곳 (직접 만드세요)
```

---

## 2. 꼭 고쳐야 하는 것 5가지

### ① 병원 이름
`index.html` 에서 `AURA` 와 `CLINIC` 을 찾아 바꾸세요. (헤더 · 푸터 · 맨 위 `<title>`)

### ② 전화번호
`index.html` 을 열고 **찾아 바꾸기(Ctrl+H)** 로 한 번에 바꾸는 게 제일 빠릅니다.

| 찾을 것 | 바꿀 것 |
|---|---|
| `02-1234-5678` | 실제 번호 (화면에 보이는 글자) |
| `0212345678` | 실제 번호에서 하이픈 뺀 것 (누르면 전화 걸리는 부분) |

### ③ 가격
가격은 **두 군데**에 있습니다. 둘 다 바꿔야 합니다.

- `index.html` 의 `<section id="price">` 안 — 화면에 보이는 금액
- `assets/js/main.js` 맨 위 `PRICE` — 계산기가 쓰는 금액

```js
const PRICE = {
  normal: 1500,   // 슈링크 1샷 정가
  event : 1000,   // 슈링크 1샷 오픈 이벤트가
};
```

### ④ 주소 · 진료시간
`index.html` 의 `<section id="info">` 안에서 `○○` 로 표시된 부분을 채우세요.

### ⑤ 링크 연결
카카오톡 · 인스타그램 · 유튜브 · 블로그 주소가 아직 비어 있습니다.
`data-todo` 라고 적힌 곳을 찾아서 이렇게 바꾸면 됩니다.

```html
<!-- 바꾸기 전 -->
<a href="#" data-todo="카카오톡 채널 주소로 교체">

<!-- 바꾼 뒤 -->
<a href="https://pf.kakao.com/_내채널주소" target="_blank" rel="noopener">
```

> 아직 안 바꾼 링크를 누르면 "아직 주소를 연결하지 않았습니다" 안내창이 뜹니다.
> 전부 바꾸면 이 안내창은 더 이상 나오지 않습니다.

## 3. 사진 넣는 법

지금은 사진 자리가 **점선 상자**로 표시돼 있습니다. (`사진이 들어갈 자리`, `원장님 사진` 등)

1. `assets/img/` 폴더를 만들고 사진을 넣습니다.
2. `index.html` 에서 아래처럼 바꿉니다.

```html
<!-- 바꾸기 전 -->
<div class="intro__ph ph" aria-hidden="true"><span>사진이 들어갈 자리</span></div>

<!-- 바꾼 뒤 -->
<div class="intro__ph"><img src="assets/img/interior.jpg" alt="진료실 내부"></div>
```

권장 크기

| 자리 | 비율 | 권장 픽셀 |
|---|---|---|
| 콘셉트 사진 | 세로 4:5 | 1200 × 1500 |
| 대표 이미지 | 가로로 넓게 21:8 | 2100 × 800 |
| 원장님 사진 | 세로 4:5 | 1200 × 1500 |

## 4. 색 바꾸는 법

`assets/css/style.css` 맨 위 `:root` 안의 값만 바꾸면 사이트 전체 색이 한 번에 바뀝니다.

```css
--lav:  #8f8fc0;   /* 포인트 색 (버튼, 강조) */
--ink:  #45455f;   /* 제목 글씨색 */
--sky:  #dfe8f7;   /* 배경 하늘색 */
--dark: #3c3c4c;   /* 푸터 */
```

## 5. 인터넷에 올리는 법 (무료)

가장 쉬운 방법은 **GitHub Pages** 입니다.

1. 이 저장소를 GitHub 에 올립니다.
2. 저장소 → **Settings** → 왼쪽 메뉴 **Pages**
3. Source 를 `Deploy from a branch`, Branch 를 `main` / `/ (root)` 로 지정 후 저장
4. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 으로 접속됩니다.

나중에 `내병원이름.com` 같은 주소를 쓰고 싶으면 도메인을 구입한 뒤
같은 Pages 화면의 **Custom domain** 에 입력하면 됩니다.

## 6. 만들어 둔 기능

- 스크롤하면 헤더에 흰 배경이 생김
- 스크롤할 때 섹션이 하나씩 부드럽게 나타남
- 오른쪽에 항상 떠 있는 예약바 (PC) / 아래 고정바 (모바일)
- 모바일에서 햄버거 메뉴
- **샷 수 계산기** — 샷 수를 움직이면 정가·이벤트가·할인액이 자동 계산됨
- 휴대폰 · 태블릿 · PC 모두 대응
