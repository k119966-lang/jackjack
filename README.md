# 슈리링의원 홈페이지

서울 강남구 강남대로 438 스타플렉스 301호 · 집속초음파(슈링크) 중심 피부시술 · 30분 단위 완전예약제

HTML + CSS + vanilla JS. 프레임워크·빌드 도구 없음. 외부 요청은 Google Fonts 하나뿐입니다.

---

## 로컬 실행

빌드 과정이 없습니다. 정적 서버만 띄우면 됩니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

`file://` 로 직접 열어도 대부분 동작하지만, 폰트와 상대 경로 때문에 서버로 여는 편이 정확합니다.

### 카피 검사

의료광고법 금지 표현을 정규식으로 검사합니다. **카피를 고칠 때마다 돌리십시오.**

```bash
python3 tools/check-copy.py index.html privacy.html
```

HTML 주석과 `<script>`는 검사에서 제외되므로, 주석에 적은 경고 문구는 걸리지 않습니다.
검토를 마친 정상 표현은 스크립트 상단 `ALLOW` 목록에 있습니다.

## 필요한 자산 (`assets/`)

현재 `assets/`는 비어 있습니다. 아래 파일이 필요합니다.

| 파일 | 규격 | 용도 |
|---|---|---|
| `logo.svg` | SVG 권장. 없으면 배경 투명 PNG, 높이 144px 이상(@2x) | 헤더 로고. 현재는 텍스트로 조판 중 |
| `og-image.png` | **1200×630px (1.91:1)**, 1MB 미만 | Open Graph 카드 |
| `favicon.svg` | SVG | 파비콘 |
| `apple-touch-icon.png` | 180×180px | iOS 홈 화면 |

> ⚠️ **로고 원본 파일이 필요합니다.** `reference/01-logo.png`는 177×232 캡처이고
> 배경이 크림색으로 구워져 있으며 하단에 57px 여백이 있어 헤더에 쓸 수 없습니다.
>
> ⚠️ **로고를 다시 만들 때**: 의료법 시행규칙 제40조상 종류명칭(`의원`)의 글자 크기는
> 고유명칭(`슈리링`)의 **1/2 이상**이어야 합니다. `의원`만 작게 줄이지 마십시오.
> 제공된 로고는 네 글자가 같은 크기라 요건을 충족합니다.

### 이미지를 추가할 때

본문에는 이미지를 넣지 않고 자리와 권장 규격만 주석으로 남겼습니다(브리핑 §5).
추가하신다면:

- ⛔ **시술 장면 사진·영상을 넣지 마십시오.** 핸드피스가 얼굴에 닿는 클로즈업,
  마킹된 얼굴, 환부 클로즈업은 의료법 제56조에 걸립니다.
- ⛔ **시술 전후 비교 사진을 넣지 마십시오.** 환자 동의를 받아도 금지입니다.
- ✅ 가능: 진료실·대기 공간·장비 외관 사진, 추상 일러스트, 개념도

## 설계 메모

브리핑과 다르게 한 것, 그리고 그 이유입니다. 자세한 근거는 `PLAN.md`에 있습니다.

| 항목 | 브리핑 | 실제 | 이유 |
|---|---|---|---|
| 섹션 순서 | 가격표 → 부작용 | **부작용 → 가격표** | 시행령 제23조가 부작용 고지의 **배치와 가독성까지** 규제합니다. 시술 설명과 위험 고지 사이에 가격표가 끼면 불리합니다 |
| 섹션 순서 | 진료 방식이 3번째 | **진료 방식을 예약 그룹 앞으로** | 시술 설명과 부작용을 가르지 않기 위해서입니다 |
| 지도 | `{{지도임베드}}` | **임베드 없음** | §3의 임베드 요구와 §5의 "외부 요청은 Google Fonts만"이 충돌합니다 |
| 토큰 | `--sand`가 보조 텍스트 | **`--sand-text` 추가** | `--sand`는 paper 위 3.29:1로 §5의 4.5:1을 못 넘습니다. 색조·채도는 그대로 두고 명도만 낮췄습니다 |
| 파일 | 7개 | **+ `privacy.html`, `tools/check-copy.py`** | 처리방침은 링크만 있고 대상이 없으면 안 됩니다. 검사기는 최우선 제약을 강제하기 위한 것입니다 |

### 색 사용 제한 (실측 명암비)

`css/style.css` 상단 주석과 `CLAUDE.md`에 표로 정리되어 있습니다. 요약:

- `--bronze` / `--bronze-hi` — **paper 위 텍스트 금지** (2.87:1 / 1.96:1). 장식 전용
- `--line` — **장식용 구분선 전용** (1.32:1). 입력 테두리로 쓰면 안 됩니다
- `--seal` — paper 위는 가능(5.88:1), **ink 배경 위는 금지**(2.65:1)
- `--sand` — 본문 텍스트 불가(3.29:1). 입력 테두리·아이콘 경계용
